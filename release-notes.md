## 1.0.0

First release of Forma for nopCommerce 5.00.

- Four presets: Atelier, Living, Luma and Noble.
- Typography, layout, button and color scheme settings, with six color schemes, in the Forma theme core plugin.
- Home page built from sections: hero slideshow, product grid, category grid, image with text, rich text, testimonials, logo list and newsletter, each with its own color scheme and padding, and translations per language.
- Mega menu from nopCommerce's Grid menu template, a More menu for long menus, and a side drawer menu on phones.
- Search dialog with nopCommerce's search autocomplete.
- Product cards with a second picture on hover, quick view and quick add.
- Sticky add to cart bar on phones and a cart drawer.
- Settings and home page sections per store in multi-store installations.
- Right-to-left language support.
