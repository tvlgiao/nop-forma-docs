Forma is an editorial storefront theme for nopCommerce 5.00. It comes as one package with two parts:

- the **Forma theme**: the storefront views, styles and scripts;
- the **Forma theme core** plugin: where you set fonts, colors and layout, and build the home page. No code needed.
