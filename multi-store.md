Forma stores its settings per store. Choose a store in the **store scope** selector at the top of the Forma settings page (**Configuration → Local plugins → Forma theme core → Configure**).

## Appearance per store

With a store selected, tick the override box next to a setting to give that store its own value. Settings you don't override use the value for all stores.

For color schemes, tick **Override color schemes for this store**.

## Home page sections per store

On the home sections page (**Edit home page sections**), with a store selected:

- any change you make gives that store its own section list;
- the page tells you whether the store has its own section list or uses the section list of all stores;
- **Use the section list of all stores** returns the store to the shared list.
